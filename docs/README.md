# FixIT-Pro documentation

FixIT-Pro matches home repair requests in the Santa Clara area to local technicians. It searches technician profiles in Pinecone and uses a local Qwen model to write a short recommendation. For a quick start, see the [project README](../README.md); for a 2-minute walkthrough, watch the [demo video](../FixIT-Pro-demo.mp4).

# Setup and configuration

## Prerequisites

- Python 3.10 or later
- A Pinecone account with an index that uses an **integrated embedding model** and embeds the `chunk_text` field
- A Qwen 2.5 Instruct model in GGUF format, for example `qwen2.5-3b-instruct-q4_k_m.gguf` from [Hugging Face](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF)
- About 3 GB of free memory for the model

## Install

```bash
git clone https://github.com/programmer11/FixIT-Pro.git
cd FixIT-Pro
pip install -r requirements.txt
```

`llama-cpp-python` compiles native code on install, which can take several minutes.

## Configure

Create a `.env` file in the project folder. It is git-ignored; never commit it.

| Variable | Required | Purpose |
| --- | --- | --- |
| `PINECONE_API_KEY` | Yes | Pinecone API key |
| `PINECONE_INDEX_NAME` | Yes | Name of the Pinecone index |
| `QWEN_MODEL_PATH` | Yes, unless the default path exists | Full path to the GGUF model file |
| `ADMIN_PASSWORD` | No | Enables the `/admin` page. Without it, admin requests return "Admin is disabled" |

Example:

```bash
PINECONE_API_KEY=your-pinecone-key
PINECONE_INDEX_NAME=your-index-name
QWEN_MODEL_PATH=/path/to/qwen2.5-3b-instruct-q4_k_m.gguf
ADMIN_PASSWORD=choose-a-strong-password
```

Values in `.env` override variables already set in your shell. The server reads `.env` only at startup, so **restart the server after changing it**.

## Run

```bash
python3 -m uvicorn app:app --port 8000
```

| URL | What it is |
| --- | --- |
| http://localhost:8000 | Landing page and search |
| http://localhost:8000/admin | Admin sign-in and profile upload |
| http://localhost:8000/docs | Interactive API docs generated by FastAPI |

The server runs only while the terminal stays open. Press Ctrl+C to stop it. To use a different port, change `--port`.

## Load profiles

A fresh Pinecone index has no profiles, so searches return nothing until you load some. Either:

- upload a JSON file on the [admin page](admin-guide.md), or
- place `santa_clara_home_repair_profiles.json` next to the notebook and run `home_repair_rag.ipynb` from top to bottom.

See [Profile data format](data-format.md) for the file layout.

## Performance notes

- Search returns in about a second.
- The first recommendation after startup loads the model, which can take a minute or more on CPU. Later ones are faster but can still take 30–60 seconds.
- The model runs with 4 CPU threads, a context of 8,192 tokens, temperature 0 and at most 600 output tokens. These are set in `rag.py`.

## Costs

Pinecone charges for storage, embedding and search according to your plan. Each search and each upload uses Pinecone's embedding model. The Qwen model runs locally and has no per-request cost.
